# Migrate model weights to Hugging Face Hub

Model weights and test data are currently hosted on Google Drive. Migrate to Hugging Face Hub for better reliability, versioning, and integration.

Benefits:
- No more Google Drive download flakiness/rate limits
- Proper versioning with git-lfs
- huggingface_hub Python API for programmatic downloads
- Community visibility — people can find and use pretrained models
- Free hosting for public models
- Can use HF cache system so users don't re-download

What to migrate:
- Pretrained model weights (flow generator, feature extractor, sequence models)
- Test data archive (~1GB used by setup_tests.py)
- Any other large artifacts currently on Google Drive
