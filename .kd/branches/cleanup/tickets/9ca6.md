# Docker build modernization

Current Docker setup was built while learning Docker — likely has suboptimal layering, redundant images, and unnecessary complexity. Three separate Dockerfiles (gui, headless, full) may be consolidatable.

Investigate:
- Can we use a single Dockerfile with build args/stages instead of 3 separate files?
- Layer ordering: are we busting cache unnecessarily?
- Multi-stage builds to reduce final image size
- Switch from Miniconda to uv or pip for faster, lighter installs
- CUDA base image selection: are we using the right variant (runtime vs devel)?
- .dockerignore optimization
- BuildKit features we should be using
- Best practices for PyTorch + PySide6 Docker images
