# Python version modernization

Upgrade deepethogram from Python 3.8 to 3.11+. Track all dependency relaxation, testing, and compatibility work.

## Acceptance Criteria

- [ ]

**Note (2026-03-29 15:45):** Investigation summary: the original requires-python constraint of >=3.8,<3.9 was a leftover from the PySide2 era, not an active dependency requirement. The dependency audit found no package that actually blocked Python 3.9+. The real blockers for Python 3.11 were scipy<1.8 and scikit-learn<1.1 being too old for 3.11. pytorch_lightning==1.6.5 was identified as the main compatibility risk, but it worked in practice. A full investigation report was written and is preserved in the agent workspace.

**Note (2026-03-29 15:45):** Commits on cleanup branch for this work: 3825369 docs: checkpoint python version investigation; 455b7c5 build: target python 3.11; 4126747 Update Ruff target to Python 3.11; 5d8bf60 Update Docker images for Python 3.11 builds. Remaining follow-up is intentionally out of scope for this ticket: GPU tests have not yet been run on Python 3.11, pytorch_lightning==1.6.5 remains pinned and should be upgraded in a separate future task, and Docker images have not yet been built and verified locally due ARM Mac limitations.
