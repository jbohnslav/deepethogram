# API and code bugs (add_label_to_project, matplotlib backend)

Two standalone code bugs:

- #116: projects.add_label_to_project() is broken — when a label CSV lacks a 'background' column, the function uses index_col=0 in pd.read_csv which eats the first data column, then inserts background. Result: first behavior column is silently deleted. Fix: verify index_col handling and test with CSVs that have/don't have an index column.

- #129: matplotlib backend conflict — flow_generator/train.py sets plt.switch_backend('agg') at import time, which breaks interactive matplotlib use when importing train modules. Consider making this conditional or removing it.
