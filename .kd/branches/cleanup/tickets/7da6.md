# PyTorch installation via uv sources

Currently torch is not in pyproject.toml dependencies at all — it's manually installed in Docker via pip. Need to add torch as a proper uv-managed dependency using tool.uv.sources with PyTorch indexes per Astral's official guide.

Per https://docs.astral.sh/uv/guides/integration/pytorch/:
- Add torch to [project.dependencies]
- Configure [tool.uv.sources] with platform markers: CPU on macOS, CUDA on Linux
- Use explicit PyTorch indexes (pytorch-cpu, pytorch-cu128)
- This eliminates the manual torch install in Docker and makes uv sync handle everything

Also need to update the Dockerfile to remove the separate torch install step — uv sync should handle it.
