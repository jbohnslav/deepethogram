# Full GUI integration testing with pytest-qt + xvfb

Set up headless GUI integration testing using pytest-qt and xvfb so we can test the full DeepEthogram GUI flow without a physical display.

Test targets:
- GUI opens without crashing
- Project creation, video import, label editing flows
- Training pipeline triggers from GUI buttons
- Config dialogs, error handling
- All menus/buttons present and clickable

Stack:
- pytest-qt (PySide6 test wrapper)
- xvfb-run (virtual framebuffer for headless Qt)
- Can run in Docker (test-gui with xvfb, or test-full with xvfb + GPU)

Implementation needs:
- Add pytest-qt to dev deps
- Install xvfb in Docker test targets
- Write GUI test fixtures (app startup, project creation, etc.)
- Wire into CI (CPU tests on ARM/x86, GPU tests on Modal)

This is the missing piece: we can test headless training (Modal/GPU) and CPU-only (Mac), but not the full GUI→training flow that users actually use.
